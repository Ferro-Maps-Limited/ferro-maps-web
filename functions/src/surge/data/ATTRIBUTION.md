# Venue location data

The checked venue coordinates in `venue-locations.json` and `venueLocations.ts` contain OpenStreetMap data © OpenStreetMap contributors, licensed under the Open Data Commons Open Database License (ODbL). Coordinates were also cross-checked against Wikidata and/or Wikipedia where noted on each row.

Lookups were done offline on 2026-11-09. The live `syncSurgeSheetEvents` job does not call a geocoder.
